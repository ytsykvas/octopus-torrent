# Frontend structure

> Last updated: 2026-10-15

The UI is React 19 + TypeScript (strict) built by Vite into `frontend/dist`, which `main.go` embeds
into the binary. The window is macOS WKWebView; the packaged app loads nothing from the network or
from the developer's disk.

## Flow

```
frontend/index.html  <div id="root"> + /src/main.tsx
  └─ src/main.tsx    createRoot(#root).render(<StrictMode><App/></StrictMode>)  (no #root → clear error)
       └─ src/App.tsx   composition root: wires real bridge functions into features
            └─ src/features/runtime-check/RuntimeCheck.tsx   loadRuntimeInfo={getRuntimeInfo}
                 button "Check Go connection" → loading → "Go go1.27.2 · darwin/arm64" | role="alert"
```

The runtime check is the 003 prototype that proves the React → Go path. The product UI replaces it:
shell 040, cards 045, import 044 and the rest.

## Folders

| Path | Holds | Rules |
|---|---|---|
| `src/features/<feature>/` | UI by feature | Components get their bridge functions **as props**, so tests need no Wails. No business rules from Go (pause, upload, wanted) |
| `src/bridge/` | The only callers of `frontend/wailsjs` ([calling Go](../bridge/calling-go.md)) | Returns `Result<T>` (the 003 `getRuntimeInfo` still rejects); no business rules |
| `src/bridge/contract/` | Decoders, encoders, enumerations, errors, ordering rules ([contract](../bridge/contract.md)) | Pure TypeScript, no Wails imports |
| `src/test/` | Test setup and the shared contract-example loader | Not product code; outside the coverage inventory |
| `frontend/wailsjs/` | Bindings generated by `go tool wails generate module` | Never edited by hand; committed |
| `src/state/`, `src/i18n/`, `src/styles/` | Planned: store (035), six languages (041), tokens and themes (039, 042) | Created by those tasks |

## Conventions

- **Composition at the root.** `App.tsx` connects real bridge functions; later the store (035) does
  this. A component never imports `wailsjs` or decides that a write succeeded.
- **Untrusted Go text.** Torrent names and file paths are shown as given, never translated. Later
  UI isolates them from bidi and control characters (045, 046).
- **Accessibility.** Native elements (`button`, `output`, `role="alert"`); the tests use Testing
  Library queries by role and label.
- **Texts.** English in the prototype; six languages through 041. Error texts come from
  `describeError` keys, not from Go.

## Build and configuration

| File | Purpose |
|---|---|
| `frontend/package.json` | Exact versions, scripts: `dev`, `build` (`tsc --noEmit && vite build`), `typecheck`, `lint`, `test`, `test:coverage` |
| `frontend/.npmrc` | `min-release-age=14`: npm installs no version younger than 14 days. Changing it needs the owner |
| `frontend/tsconfig.json` | `strict`, `noUncheckedIndexedAccess`, `noUnused*`, `noImplicitReturns` |
| `frontend/vite.config.ts` | React plugin; Vitest (jsdom), per-file 100% thresholds |
| `frontend/.oxlintrc.json` | Oxlint with type-aware rules ([testing](../development/testing.md#lint)) |
| `wails.json` | `npm ci`, `npm run build`, dev watcher `npm run dev` |
